# VS Code Xournal++ Sync

Extensão para Visual Studio Code desenvolvida para integrar e sincronizar fluxos de anotação e leitura de arquivos com o Xournal++.

## Estrutura do Pacote

- `src/extension.ts` — Código-fonte principal da extensão em TypeScript.
- `out/` — Arquivos JavaScript compilados e mapas de origem.
- `media/` — Ícones e recursos visuais da extensão (`icon.png` e `icon.svg`).
- `package.json` — Manifesto de configurações, comandos e dependências da extensão.
- `tsconfig.json` — Configurações do compilador TypeScript.

## Como Instalar (Arquivo `.vsix`)

1. Baixe o arquivo `.vsix` disponível nesta pasta.
2. Abra o **Visual Studio Code**.
3. Acesse a aba de **Extensões** (`Ctrl + Shift + X`).
4. Clique nos três pontinhos (`...`) no canto superior direito do painel de extensões e selecione **Install from VSIX...**.
5. Selecione o arquivo `.vsix` baixado para concluir a instalação.
